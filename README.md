### 👨‍💻 Sobre mim

Trabalho com **desenvolvimento web desde 2019**, sempre focado em criar interfaces modernas e responsivas, principalmente com o ecossistema SPA (Single Page Applications). Em **2024**, dei um grande passo e migrei para o desenvolvimento **Fullstack**, integrando toda a minha bagagem de Frontend com a solidez do Backend.

- 🎯 **Foco atual:** Evoluir cada vez mais na stack Fullstack (React, Angular 2+, Node.js) e criar arquiteturas robustas.
- 📚 **Aprendendo:** Novas abordagens em Frontend, escalabilidade no Backend e desenvolvimento Mobile.
- 💬 **Pergunte-me sobre:** React, Angular, Tailwind CSS, UI/UX e transição para o Fullstack.
- ⚡ **Curiosidade:** Adoro otimizar a performance de aplicações web e criar Design Systems!
